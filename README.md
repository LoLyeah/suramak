# Suramak

Local-first transcription app for macOS (Windows port next). Fully native, written in Rust.

- On-device transcription (whisper.cpp via whisper-rs), English + Indonesian first.
- Import files + microphone recording, timestamped segments, editable transcript.
- Export Markdown / TXT / JSON — take it to any LLM you like.
- Optional in-app "polish" via your own OpenAI-compatible endpoint.
- Liquid Glass UI on macOS 26+, frosted glass on Windows.

Status: scaffolding. Technical plan: `docs/PLAN.md` (in progress).
