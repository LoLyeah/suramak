0.8.1 fixes a crash that made the Android build unusable on Android 12 and later: every import, every recording that left the app, and every resume died before anything was queued. If you are on 0.8.0, this is the build to install.

There is one functional change and one process change. The app now asks the job scheduler for what it actually needs — an expedited job **or** a deadline, never both — because the platform rejects that combination with an unchecked exception that surfaced on the main thread. And the emulator smoke now builds that request on every run and throws it away, so a request the platform would refuse fails CI instead of a phone.

Known gap, not fixed here: the session limit is computed from the device's memory but has no row on the Android Device card yet. That lands in 0.8.2.
